# Club Sportivo Independiente Rivadavia — Sitio Web

Aplicación web desarrollada como trabajo práctico final de la carrera
Técnico Superior en Computación. El proyecto simula el sitio oficial del
Club Sportivo Independiente Rivadavia, construido con Next.js por primera
vez.

## Tecnologías usadas

- **Next.js**
- **React** 
- **Tailwind CSS** 

## Cómo correrlo localmente

1. Clonar el repositorio
```bash
git clone https://github.com/monticonegiaco/club-independiente-rivadavia-web.git
cd club-independiente-rivadavia-web
```

2. Instalar dependencias
```bash
npm install
```

3. Iniciar el servidor de desarrollo
```bash
npm run dev
```

El sitio estará disponible en `http://localhost:3000`
